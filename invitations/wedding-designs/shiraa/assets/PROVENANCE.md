# Original Shiraa assets

Created for this template on 13 November 2026. No customer media was used;
the couple are invented. The outfits follow a reference photo the user shared
(white kandura, ghutra and agal, black bisht with gold zari; strapless ivory
ballgown with a layered organza train, emerald earrings) as a written
description only — the photo was never an input to any generation.
Stills: Higgsfield GPT Image 2.6. Film: Higgsfield Seedance 2.5 (omni
reference, start/end frame, unlimited plan). Originals (PNG/MP4) are kept
outside the repository; the site ships optimised WebP and audio-free H.264.
